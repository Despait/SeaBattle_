Морской бой: MAX
Python 3.10+; стандартная библиотека tkinter.
Запуск: python game.py
Выберите сложность, нажмите «Новая битва». Выберите оружие и кликните по правому полю. Орудие — одна клетка, торпеда — три горизонтальные клетки (3 заряда), авиаудар — 3×3 (1 заряд). Повторные клетки исключаются. После каждого действия компьютер делает один выстрел, если битва не завершена. Флот расставляется автоматически. Слева — ваш флот. Красный крест — попадание, точка — промах.
